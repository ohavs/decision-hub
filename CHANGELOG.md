# Changelog

All notable changes to the Decision Hub project will be documented in this file.

## [Unreleased]

### Added
- Initial project setup with Next.js App Router paradigm.
- Implemented `DecisionHub` core components and intuitive routing.
- Support for 7 distinct group evaluation and decision mini-games: Finger Dice, 3D Dice Roller, Coin Flip, Random Picker, Color Roulette, Reaction Time, and Draw Straws.
- Context providers across React for consistent Language translation and States management.
- Initial creation of `PROJECT_OVERVIEW.md` and `CHANGELOG.md` for better project documentation transparency.

### Changed
- Configured application environment with newly evaluated npm dependencies via `npm install`.
- Transitioned default repository assets to minimize overhead: purged unrelated styling resources (`styles/`), cleaned `pnpm-lock.yaml`, and wiped `public/` folder dummy files (`placeholder` icons).
